# Runeshatter

A magic-themed, Bejeweled-3-style match-3 with crisp pixel-art spell effects. Swap runes even while cascades are falling.

**▶ Play:** https://golgothad.github.io/runeshatter/

- Modes: Classic, Zen, Lightning (60s, +3s per forged power-up)
- Power-ups: Flame Rune (match 4, 3×3 blast), Star Rune (L/T, row + column), Arcane Orb (match 5, clears a color), Supernova (6+, 5-wide cross); rune+rune combos
- Controls: mouse drag/click, touch swipe, keyboard (arrows/Space/H/Esc), Xbox controller (D-pad/stick, A grab, B cancel, Y hint, Start pause)
- Installable PWA, works offline; progress and records saved locally
